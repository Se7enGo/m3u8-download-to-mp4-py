# M3U8 视频下载工具

基于 DrissionPage 的 m3u8 视频嗅探与下载工具：程序启动一个独立的 Chromium 浏览器，自动监听其中所有标签页的网络请求，发现 m3u8 后解析 ts 片段列表并展示给你确认，确认后以受控速度并发下载、合并为 mp4。

## 功能

- 启动独立 Chromium 实例，不影响日常使用的 Chrome
- 监听**所有标签页**的网络请求，自动捕获 m3u8 链接
- 自动解析主播放列表并选择**最低清晰度**
- 检测到多个链接时列出清晰度、片段数、时长供你选择
- ts 片段列表缩略展示（前 5 + 后 5），确认后开始下载
- 全局请求节流 + 4 并发，尽量不触发服务器限速
- 实时显示下载进度（成功/失败/重试/速度/当前片段）
- 失败片段自动重试，跳过并记录原因；累计 3 个失败时暂停询问
- 使用 ffmpeg 无损合并为 mp4（`-c copy`，不重新编码）
- 加密（AES-128 / SAMPLE-AES）视频会明确提示暂不支持

## 环境要求

- Python 3.10+
- Google Chrome（DrissionPage 会自动启动独立实例）
- FFmpeg（合并 mp4 必需，需在 PATH 中）

FFmpeg 安装方式（Windows）：

```bash
winget install ffmpeg
# 或
choco install ffmpeg
```

安装后重新打开终端，确认 `ffmpeg -version` 可正常输出。

## 安装

```bash
pip install -r requirements.txt
```

## 使用

```bash
python main.py
```

程序会打开一个独立的 Chromium 窗口，然后在终端中：

1. 在浏览器里访问视频网站，登录并播放视频（刷新页面也可以）
2. 终端检测到 m3u8 后，按提示选择要下载的视频、确认片段列表
3. 输入视频名称（默认取当前页面标题）
4. 等待下载与合并完成，mp4 输出到 `output/`
5. 程序继续监听，可以接着下载下一个视频
6. 退出方式：直接关闭浏览器窗口，或按 `Ctrl+C`

关闭浏览器时程序会自动退出；如果此时正在下载，会立即停止并把已下载的片段保留在 `temp/` 下。

### 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--workers` | `4` | 最大并发下载数 |
| `--retry` | `3` | 单个片段最多尝试次数 |
| `--interval` | `0.15` | 全局请求间隔（秒），所有下载请求共用 |
| `--timeout` | `30` | 单次请求超时（秒） |
| `--error-threshold` | `3` | 失败片段达到该数量时暂停并询问 |
| `--temp-dir` | `temp` | 临时下载目录 |
| `--output-dir` | `output` | 输出目录 |

示例：

```bash
python main.py --workers 3 --interval 0.3 --output-dir D:\videos
```

## 下载过程中的错误处理

- 连接超时 / 网络错误 / 5xx / 429：自动重试（默认 3 次，带退避）
- 401 / 403 / 404 / 410：不重试，直接记录原因并跳过
- 失败片段累计达到阈值（默认 3 个）时暂停，可选择：
  1. 继续下载（跳过失败片段）
  2. 重新尝试所有失败片段
  3. 放弃本次任务
- 存在失败片段时，合并前会再次确认；合并后也会列出失败清单

## 常见问题

**检测不到 m3u8？**
- 确认视频确实在播放；部分网站需要先点击播放才会请求播放列表
- 刚新开的标签页若在第一秒内就加载完成，可能漏掉首次请求，刷新页面即可
- 部分网站使用加密或私有协议，程序会在终端说明原因

**提示"跳过加密视频"？**
当前版本只支持未加密的 HLS，AES-128 / SAMPLE-AES 视频无法下载。

**合并失败？**
- 检查 `ffmpeg -version` 是否可用；未安装时片段会保留在 `temp/` 下
- 个别片段损坏时可选择保留临时文件，用其他工具重新合并

**下载不到完整视频（直播流）？**
播放列表没有 `#EXT-X-ENDLIST` 时属于直播/滚动列表，程序会提示，可能只能拿到当前窗口内的片段。

**关掉浏览器后程序没有退出？**
程序每 0.3 秒检查一次浏览器连接，通常 1 秒内就会退出。若浏览器仍在后台运行（部分设置下关闭窗口不会结束进程），程序会继续等待，此时可按 `Ctrl+C` 退出。
